# UnmessIt.AI Web

Beta frontend for UnmessIt.AI.

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Default backend:

```txt
http://localhost:8000
```

Override with:

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000 npm run dev -- --host 127.0.0.1
```

Checks:

```bash
npm run lint
npm run build
```
