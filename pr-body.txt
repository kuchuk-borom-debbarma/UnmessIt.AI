## 0.1.7: Architecture Microsite, API Enhancements & Perspective Fixes

### 🏗️ Architecture & Documentation
- **Architecture Microsite:** Built a deeply technical, standalone architecture documentation microsite (`/architecture`) featuring deep dives into the Core Engine, Indexing, Querying, and Supporting Systems (EDA, Idempotency, Transactional Outbox).
- **Execution Flow Visualizations:** Added granular, vertical step-by-step UI traces at the bottom of the Indexing and Querying pages mimicking the exact backend LangGraph execution code paths. Also added a "Full Integrated Engine" view demonstrating how Ingestion, the Storage Core, and Query Generation interact in production.

### 🐛 Fixes
- **Subject/Object Inversion:** Fixed an issue where the RAG pipeline would sometimes invert the actor/patient relationship when summarizing first-person text. Updated LLM prompts in `drafts.py` and `query/__init__.py` to explicitly preserve original perspectives, following `prompt_rules.md`.
- **Note Details UI:** Fixed "Read more" expand button occasionally failing to appear for long text blocks due to CSS flexbox quirks, opting for a robust text length heuristic instead.
- **Touch Targets:** Enhanced Expand/Shrink buttons in Note Details with larger touch targets (48x48) and smooth active tap feedback, per ui-ux-pro-max guidelines.

### ✨ Features
- **Reindex API (`POST /advanced/reindex`):** Added endpoint to wipe the existing chunk/recall index and reset all ingestion jobs to re-process using the currently configured LLM and embedding models.
- **Index Metadata API (`GET /advanced/index_metadata`):** Added endpoint to retrieve statistics about which LLMs and embedding models were used to generate the chunks in the current index.
- **Metadata Storage:** Ingestion now explicitly stores the `llm_model` and `embedding_model` strings in each source chunk's metadata JSON.
- **Advanced Tag Filtering:** Added support for ANY / ALL tag filtering modes across both the frontend UI (`TagSearchSelect`) and backend database logic (handling complex `INTERSECT`-style subqueries).
- **Tag API Pagination:** Standardized the `GET /tags/` endpoint to fully support offset-based pagination (`page`, `limit`), removing the last unpaginated exception in the system.

### 🎨 UI Enhancements
- **Landing Page Redesign:** Overhauled the main landing page hero section. Added a premium brand identity, glowing gradients, and improved typography.
- **Durable Execution Demo:** Designed a "Live Retrieval" terminal-like UI to visualize the multi-stage ingestion pipeline.
- **Semantic Caching Demo:** Replaced the circular layout with a dynamic, nested Y-branch SVG flowchart. It intricately visualizes the token-saving breakdown of complex queries, complete with animated data packets smoothly tracing bezier curves.
- **Floating Dock & Routing Redesign:** Redesigned the floating dock to expand beautifully across the screen with equally distributed segments. Removed extraneous controls, simplified the user profile, and completely locked down authenticated routing to provide a seamless app experience.
