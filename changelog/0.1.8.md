## 0.1.8

## Features
- **Single Note Reindexing:** Added the `POST /advanced/reindex/{note_id}` API endpoint to surgically wipe and re-index a single note's semantic cache without affecting the rest of the workspace.
- **Note Detail UI Updates:** Added a new "Reindex Note" action button directly into the Note detail view, allowing users to instantly re-queue a specific note.

## Fixes
- **Ping Button Spammability:** Fixed the "Ping API" button in Settings to properly disable itself when loading. Added a spinning loading indicator and updated the UI text to "Pinging..." to prevent double-clicks and provide better visual feedback.
