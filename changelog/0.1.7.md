# 0.1.7

## Fixes
- Fixed an issue where the RAG pipeline would sometimes invert the actor/patient relationship (Subject/Object Inversion) when summarizing first-person text.
- Updated LLM prompts in `drafts.py` and `query/__init__.py` to explicitly preserve original perspectives, following `prompt_rules.md`.

## Features
- **Reindex API:** Added `POST /advanced/reindex` to wipe the existing chunk/recall index and reset all ingestion jobs to re-process using the currently configured LLM and embedding models.
- **Index Metadata API:** Added `GET /advanced/index_metadata` to retrieve statistics about which LLMs and embedding models were used to generate the chunks in the current index.
- **Metadata Storage:** Ingestion now explicitly stores the `llm_model` and `embedding_model` strings in each source chunk's metadata JSON.
