## 0.1.2
**Release Date**: 2026-07-04

## Bug Fixes & Improvements
- **Nginx Proxy Timeout**: Increased `proxy_read_timeout` to 600s in the dockerized Nginx config to prevent 504 Gateway Time-out errors on long-running LLM and embedding operations.
- **Header Overlay Fix**: Fixed an issue where the top navigation bar's container blocked pointer events, making the "Release history" button unclickable. Banners remain fully interactive.
- **Config Ping API**: Added a "Ping API" test button to the LLM and Embedding config creation/editing modal (in Settings). You can now test API connectivity directly from the UI, with proper handling and surfacing of upstream provider status codes and error messages.
